# Tokens

One scale, two exports: CSS custom properties (`--ui-*`) for components, and the `tokens` object for docs or JS. Values are kept in sync by hand between `src/styles/tokens.css` and `src/tokens/tokens.ts`.

Semantic color is restrained — ink, paper, pine, and a copper accent — with danger / warning / success / info for status. Pairings below are authored for **WCAG AA** (text ≥ 4.5:1, UI chrome ≥ 3:1).

## Space

Four-pixel base. Components use `--ui-space-1` through `--ui-space-9` rather than ad-hoc padding.

## Radius

`sm` 4px for tight controls, `md` 8px for buttons and inputs, `lg` 12px for panels, `full` for badges.

## Motion

`--ui-duration-fast` 120ms and `--ui-duration-med` 200ms with `--ui-ease-out` (`cubic-bezier(0.2, 0, 0, 1)`). Hover and focus use color only — no bounce, no layout shift. `prefers-reduced-motion: reduce` collapses durations to 0.01ms in `base.css`.
